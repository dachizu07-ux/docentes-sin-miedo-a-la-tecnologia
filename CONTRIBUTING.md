
# Cómo contribuir a Docentes sin Miedo a la Tecnología

¡Bienvenidos a este proyecto educativo!

Nuestro objetivo es ayudar a docentes que sienten inseguridad al utilizar herramientas digitales, mediante guías prácticas, sencillas y accesibles.

## ¿Quiénes pueden colaborar?

Docentes, facilitadores, estudiantes y cualquier persona interesada en mejorar los recursos educativos del proyecto.

## ¿Cómo puedes contribuir?

- Proponiendo nuevas herramientas digitales para la enseñanza.
- Sugiriendo temas para futuras guías.
- Identificando errores o instrucciones poco claras.
- Compartiendo actividades prácticas.
- Recomendando mejoras para facilitar el aprendizaje.

## Pasos para colaborar

1. Lee el archivo README.md para conocer el proyecto.
2. Revisa los Issues existentes para identificar necesidades o mejoras propuestas.
3. Si tienes una sugerencia nueva, crea un Issue explicando qué deseas mejorar y por qué.
4. Para modificar un documento, crea una rama de trabajo.
5. Realiza los cambios y presenta un Pull Request.
6. Revisa las observaciones recibidas antes de integrar la contribución.

## Recomendaciones

- Utiliza un lenguaje claro, sencillo y respetuoso.
- Explica los procedimientos paso a paso.
- Verifica la información antes de compartirla.
- No publiques datos personales de estudiantes.
- Respeta los derechos de autor de imágenes y materiales.
- Mantén las contribuciones relacionadas con el propósito educativo del proyecto.

## Primera mejora propuesta

Incorporar una sección de autoevaluación a la guía básica de Canva, para que los docentes puedan comprobar sus aprendizajes.

## Estado del proyecto

El proyecto se encuentra en su etapa inicial. Las contribuciones y mejoras futuras se incorporarán progresivamente, después de su revisión.

¡Gracias por contribuir a que más docentes aprendan tecnología con confianza!
